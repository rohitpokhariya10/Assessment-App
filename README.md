# Assessment App
 A responsive single-page assessment application built with React, useReducer, Talwind  CSS , and 
 built with React, useReducer, Talwind CSS, and localStorage.

# Project setup instructions
1) Create a folder
2) Run this command into this folder terminal : git clone https://github.com/rohitpokhariya10/Assessment-App .
3) Run this command to install required packages : npm i
4) to run locally use this command : npm run dev

# Features
1) 10 assessment questions stored in a local JSON file
2) Single-Page React application
3) One useReducer used to manage:
   - Questions
   - Current Questions
   - User answers
   - Timer
   - Quiz status
4) Start screen with:
   - Total number of questions
   - Time limit
   - Start Assessment button
5) Assessment screen with:
   - Current question
   - Multiple-choice options
   - Current question number
   - Progress indicator
   - Countdown timer
   - Previous button
   - Next button
   - Submit button
6) 5-minute countdown timer
7) Automatic submission when the timer reaches 00:00
8) User can continue from the same question after refreshing
9) Result screen with:
    - Score
    - Total questions
    - Percentage
10) Review section showing:
    - Question
    - Selected answer
    - Correct answer
    - Correct / Incorrect status
11) Restart Assessment option
12) Fully responsive design
13) No horizontal overflow on smaller devices
14) Talwind CSS used for all major styling
